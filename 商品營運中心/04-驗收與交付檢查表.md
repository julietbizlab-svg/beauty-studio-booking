# 驗收與交付檢查表

每位業主開通後複製一份並逐項驗收。

## 權限、服務與畫面

- [ ] 業主可進入自己的工作室，未授權者不能進入。
- [ ] 店名、地址、聯絡方式與公告正確，無測試網址或其他工作室資料。
- [ ] 服務名稱、價格、時長與順序正確。
- [ ] 日期與時段只顯示業主可預約時間。
- [ ] 業主端營業時段的週幾、開始時間、結束時間與刪除按鈕四欄等高並整齊對齊。
- [ ] 營業時段載入或儲存成功後按鈕變暗；修改、新增或刪除時段後才重新亮起。
- [ ] 美甲、美睫不會誤跳評估；旗艦服務顯示正確題庫。
- [ ] 評估題庫預設只顯示摘要；點「編輯題目」才展開，修改後才能儲存，成功後自動收合。
- [ ] 系統鎖定題沒有編輯入口，手機上的取消／儲存按鈕等寬且不溢出。

## 預約、訂金與通知

- [ ] 測試預約可正常快速送出。
- [ ] 客戶通知含正確服務、日期與時間。
- [ ] 訂金銀行、帳號、金額與 24 小時說明正確。
- [ ] 轉帳回報會通知業主，確認訂金會通知客戶。
- [ ] 業主確認訂金後，客戶「我的預約」明確顯示已收訂金金額、本次預約已保留與確認時間。
- [ ] LINE 成立通知明確顯示工作室已收到訂金金額，並列出正確服務、日期與時間。
- [ ] 業主預約卡可清楚區分待收訂金、待核對訂金及已收訂金；已收案件顯示確認時間。
- [ ] 設定資料較慢載入時，客戶切換「我的預約」不會出現英文技術錯誤，其他預約仍可查看。
- [ ] 逾期未付依規則失效、通知並釋放時段。
- [ ] 同一事件不會短時間重複發送。
- [ ] 已繳訂金預約引導改期並通知業主，不直接取消。
- [ ] 完成服務後會依該服務週期回訪；客戶已有同服務預約時不重複提醒。
- [ ] 回訪訊息的一鍵預約連結會開啟正確工作室並自動選定原服務。

## 客戶與照片

- [ ] 客戶資料儲存後按鈕回到未修改狀態。
- [ ] 每位客戶有獨立相簿，照片由新到舊正常顯示。
- [ ] 不會看到其他工作室或其他客戶資料。

## 旗艦 AI 版加驗

- [ ] AI 只推薦本店已啟用且可公開預約的服務。
- [ ] AI 草稿與實際服務一致，前後保養內容不混淆。
- [ ] 霧眉、霧唇內容不混用，且全部使用繁體中文。
- [ ] AI 不做健康、施作適合性或效果判斷；不確定時轉人工。
