# 續租、升級、修改與售後

所有後續需求先分類，再決定是日常設定、加購或工程除蟲。

## 續租／升降級

- 確認工作室、目前方案、舊／新到期日、租金與付款。
- 標準版升旗艦版前，先收齊知識庫、評估題庫與轉人工規則並完成驗收。
- 旗艦降標準版前，先說明停用功能與資料保留方式，不直接刪除歷史資料。

## 小幅修改

1. 記錄修改前內容與業主要求。
2. 能由業主端設定的項目，教業主自行處理。
3. 需平台代改或影響共用系統時，先確認範圍、費用與完成日。
4. 共用程式修改先在 v2-test 測試，不直接改 production。

## 除蟲需要收集

- 工作室與方案（不收 token 或 LINE user ID）。
- 發生日期時間、使用入口與操作步驟。
- 預期結果、實際結果與遮蔽個資的截圖。
- 是否每次發生、哪些服務受影響。

處理順序：先在 v2-test 重現，修正後跑自動與實機測試。遠端部署前備份 v2-test D1 並取得當次授權；production 需另一次授權，不能沿用。

修正完成後，不只更新工程程式；同一次工作還要同步更新「商品營運中心」相關文件與 current 安裝包。若安裝包尚未重建／驗證，必須明確記錄為不可交付，避免日後誤用舊版再次帶回 bug。
