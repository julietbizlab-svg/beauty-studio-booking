# 平台端開通業主步驟

一般開通不需要部署、資料庫指令或重建 LINE OA／LIFF。

## 1. 建立工作室

1. 確認成交資料、方案、租期與付款狀態。
2. 從 Juliet Studio OS 平台管理中心新增工作室。
   - 工作室清單上方的「待開通、試用中、正式租用、即將到期」數字格可直接點選篩選；再次點同一格會回到全部工作室。
3. 填寫正式店名，選擇標準版或旗艦 AI 版。
4. 設定試用／租用期間。
5. 確認不是平台主帳號或展示工作室。

## 2. 產生並傳送一次性邀請

1. 為新工作室產生一次性業主邀請。
2. 私下傳給真正業主，請他用長期管理用的 LINE 開啟。
3. 邀請過期只需重新產生，不重建工作室或 OA。

## 3. 業主完成首次綁定

業主確認店名、填寫顯示名稱、同意使用規範與隱私說明後送出。平台應顯示已綁定；不要請業主提供 LINE user ID。

## 4. 完成設定

依成交資料設定店名、地址、服務、價格、時長、訂金、服務前叮嚀、營業時段、公休日與銀行資料。

- 標準版不開啟 AI 評估功能。
- 旗艦 AI 版才設定知識庫、題庫、服務評估與轉人工規則。

## 5. 提供入口與驗收

- 業主從共用 OA 的「業主端」進入自己的工作室。
- 客戶使用該工作室的客戶入口預約。
- 在平台工作室卡片按「管理」，複製該工作室的「專屬客戶入口」；既有工作室若尚未建立，先按「建立客戶入口」。
- 使用不同於業主的 LINE 測試帳號開啟入口，確認店名、服務、營業時間、評估題庫與預約都屬於同一工作室。
- 立即依 `04-驗收與交付檢查表.md` 在手機 LINE 實機驗收。

## 異常處理

| 情況 | 處理 |
|---|---|
| 邀請過期 | 重新產生邀請。 |
| 尚未綁定 | 確認邀請有效並請業主完成首次設定。 |
| 綁定錯誤 | 停止操作，走正式更正流程，不直接改資料。 |
| 進入錯誤工作室 | 停止使用並檢查權限，不公開識別資料。 |
| 需要自有品牌 OA | 改走加購建置，不混入一般開通。 |
| 系統錯誤 | 先在 v2-test 重現，不直接碰 production。 |
