# 商品營運中心｜先打開這裡

這是 Juliet Studio OS 對外出租與平台營運的唯一入口。

有業主要詢問、試用、租用、升級或報修時，只需打開本資料夾，不必進入程式碼、Cloudflare、資料庫或其他工程資料夾。

## 遇到什麼事，要開哪一份

| 情況 | 打開檔案 |
|---|---|
| 業主詢問有哪些方案 | `01-可販售方案總表.md` |
| 業主決定試用或租用 | `02-業主成交與開通資料表.md` |
| 收到款項、準備建立帳號 | `03-平台端開通業主步驟.md` |
| 開通完成、準備交給業主 | `04-驗收與交付檢查表.md` |
| 續租、升級、修改或除蟲 | `05-續租升級修改與售後.md` |
| 不確定能不能答應或是否需加價 | `06-不可直接承諾與另行報價.md` |
| 保存每位已成交業主的資料 | `業主個案/` |
| 平台需要維護或重建 | `安裝包/`（一般新業主開通不使用） |

## 最簡單的出租流程

1. 用「可販售方案總表」介紹標準版、旗艦 AI 版與加購服務。
2. 確認方案後，在「業主個案」建立該工作室資料夾，複製一份「業主成交與開通資料表」保存。
3. 收齊資料並確認付款／試用條件後，照「平台端開通業主步驟」建立工作室與邀請。
4. 業主完成 LINE 綁定後，照「驗收與交付檢查表」實機驗收。
5. 日後續租、升級、修改或報修，一律記錄在「續租升級修改與售後」。

## 一般新業主開通不需要做的事

- 不需要複製整個專案或重新部署 Worker／Pages。
- 不需要新增資料庫或執行 migration。
- 不需要為每位業主重建 LINE OA、Messaging API、LINE Login 或 LIFF。
- 不需要接觸 token、Channel Secret、`.dev.vars` 或任何密鑰。

一般訂閱只需在平台建立獨立工作室、選擇方案、設定租用期間，再讓業主透過一次性邀請完成 LINE 綁定。

## 三條安全底線

1. 不在聊天、表單或截圖中收集／公開 LINE user ID、token、Channel Secret 或密鑰。
2. 不把展示工作室、平台主帳號當成正式出租工作室。
3. 部署或遠端資料庫寫入必須先備份並取得當次明確授權；一般開通不會用到。

## 版本同步規則

往後只要系統有任何已完成的功能修改、文字調整、流程變更或除蟲，即使主結構沒有改變，也必須在同一次工作中同步處理：

1. 更新本資料夾內受影響的商品說明、開通步驟、驗收表與售後文件。
2. 若修改涉及可安裝程式，重新產生本資料夾「安裝包」內的 current 安裝包與 SHA-256。
3. 舊安裝包不得繼續標示為 current；應列為失效或封存，不能提供新業主使用。
4. 重新執行適當測試與安裝包安全檢查後，才能說明這一版可交付。
5. 若修改尚未完成或尚未驗收，不得先更新為可販售／可交付版本。

目標是讓本資料夾永遠只把「已修好、已驗證、目前可以使用」的版本放在最明顯的位置，避免誤開舊檔或有問題的安裝包。
