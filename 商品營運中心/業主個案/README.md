# 業主個案存放區

每位確定試用或租用的業主，在這裡建立一個自己的資料夾。

建議命名：

`工作室名稱－方案－開通日期`

每個業主資料夾只保存：

1. 從 `02-業主成交與開通資料表.md` 複製的成交與設定資料。
2. 從 `04-驗收與交付檢查表.md` 複製的驗收結果。
3. 從 `05-續租升級修改與售後.md` 複製的售後紀錄。
4. 雙方已確認的方案、費用與客製範圍。

不要保存：

- LINE user ID、token、Channel Secret、密碼或 `.dev.vars`。
- 客戶照片、健康資料或不必要的個人資料。
- production 資料庫、D1 備份或整份系統原始碼。

若業主尚未確定租用，不必建立資料夾；先使用上一層的方案表介紹即可。
