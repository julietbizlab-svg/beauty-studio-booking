# 小修改指南

## 業主自己可改

- 工作室公告
- 服務名稱、價格、時長與說明
- 服務前叮嚀
- 營業時段
- 訂金與匯款顯示資料

以上應優先從業主端設定，不修改程式。

## 平台可代改

- 方案與租期
- 工作室名稱更正
- 旗艦問卷指派
- 客製品牌 OA
- 非安全類顯示文字與品牌樣式

## 必須由開發者處理

- 預約狀態規則
- 權限與 tenant 隔離
- 通知發送流程
- D1 schema／migration
- LINE token routing
- 健康安全題與 AI 限制

## 檔案修改對照

| 修改類型 | 原始檔 | 部署檔 |
|---|---|---|
| 客戶畫面 | `customer-ui/` | `docs/` |
| 業主畫面 | `owner-admin/` | `docs/owner/` |
| 平台畫面 | `platform-admin/` | `docs/platform/` |
| API／規則 | `backend/src/` | Worker bundle |

修改前端後必須同步鏡像與更新 cache-busting 版本；修改後端後必須增加或更新測試。
