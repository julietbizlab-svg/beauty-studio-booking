# 業主使用說明書

## 第一次登入

1. 用準備長期管理工作室的 LINE 帳號開啟平台傳來的邀請。
2. 填寫工作室名稱與業主顯示名稱。
3. 閱讀並同意使用規範。
4. 完成後，日後從 OA 的「業主端」進入即可。

## 開始營業前

1. 在「服務管理」新增服務名稱、價格、時長、訂金與服務回訪週期；填 0 代表停用該服務的回訪提醒。
2. 填寫每項服務的服務前叮嚀。
3. 在「營業時段」設定每週可預約時間並儲存。
4. 在「店面設定」填寫品牌、公告、匯款資料及此工作室的客戶端 LIFF 網址。
5. 用客戶入口試下一筆預約，確認日期、時間與通知內容。

## 每日操作

- 查看今日與月曆預約。
- 審核新預約與客戶補件。
- 受理後確認客戶的 24 小時訂金期限。
- 收到匯款後按「確認訂金」，預約才正式成立。
- 完成服務後更新狀態，讓系統安排後續提醒。

## 服務週期回訪與再次預約

- 系統從服務完成日依各服務的「回訪週期」計算提醒日期，只提醒已綁定 LINE 的客戶。
- 回訪通知使用該工作室自己的 LINE OA；不同工作室不會混用。
- 客戶若已預約同一項服務，尚未送出的回訪通知會自動停止，避免重複推銷。
- 店面設定已填入客戶端 LIFF 網址時，客戶點訊息即可開啟並自動選定原服務；未填網址時只會收到文字提醒。
- 取消、過期或未完成的服務不會啟動回訪週期；LINE 發送失敗則沿用安全重試機制。

## 旗艦版服務評估題庫

1. 先到「服務管理」編輯服務，為每個服務選擇正確的新客評估題庫；補色或續色若不需評估，可選「不使用評估」。
2. 到「店面設定」最下方按「載入題庫」，系統只會展開目前服務已啟用且支援的題庫。
3. 一般服務需求題可以修改；健康、安全、療程與照片規格由系統鎖定，不可刪除或改寫。
4. 按最下方「儲存設定」成功後，題庫會自動收起；需要查看時再按「載入題庫」。

編輯單一題目時，先按「編輯題目」展開。沒有修改時「儲存修改」會保持停用；修改題目或選項後才會亮起。儲存成功後該題會自動收合。按「取消編輯」會還原尚未儲存的內容。系統鎖定題只能查看，不提供編輯按鈕。

「載入題庫」不是上傳文件，也不是 LINE 客服知識庫。LINE 客服規則、價目、術前術後內容與人工轉接規則，應填在 AI 店務秘書／工作室知識設定中。

## 要求客戶補照片或補答

- 按下「要求補照片」或「通知客人補答」後，等待畫面完成再操作，不需連續點擊。
- 系統會在傳送期間鎖定按鈕；同一預約、同一通知類型在 2 分鐘內只保留第一筆，避免客戶收到重複訊息。
- 「LINE 通知已排入傳送」代表通知已建立，但不等於 LINE 已確認送達；如需查證，請由平台端查看通知的 `sent_at`，不要只看業主畫面推測。

## 常見提醒

- 不要把業主邀請轉傳給別人。
- 不要在聊天中傳送 token、密碼或 LINE user ID。
- 要更名、換綁 LINE、升降級或續約，請聯絡平台處理。
- 客戶超過訂金期限未付款，系統會取消預約、通知客戶並釋放時段。
