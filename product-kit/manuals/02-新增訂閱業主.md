# 新增訂閱業主

## 平台負責人操作

1. 開啟平台管理中心。
2. 選擇標準版、旗艦版或試用方案。
3. 填寫必要的工作室資料與租期。
4. 旗艦版選擇正確專業與評估問卷。
5. 確認付款或試用核准。
6. 產生一次性業主邀請，私下傳給本人。
7. 等業主用自己的 LINE 完成認領。
8. 驗證業主只能進入自己的工作室。
9. 驗證客戶入口顯示正確品牌、服務與方案功能。
10. 在工作室卡片的「管理」內複製「專屬客戶入口」交給業主；既有工作室若尚未建立，先按「建立客戶入口」。

專屬客戶入口由系統以不可猜測的代碼安全對應工作室，不要自行改網址、加入 tenant ID，或拿展示入口代替正式工作室入口。

## 不需要做

- 不為每位業主建立新的 Worker 或 Pages。
- 不重建共用 OA、LINE Login 或 LIFF。
- 不要求業主提供 LINE user ID。
- 不直接修改 D1 建立正式業主。
- 不把 tenant ID、token 或 Cloudflare 後台資料交給業主。

## 交付給業主的內容

- 業主入口
- 客戶預約入口
- 方案與租期
- 首次登入說明
- 客服聯絡方式
- [03-業主使用說明書.md](03-業主使用說明書.md)
