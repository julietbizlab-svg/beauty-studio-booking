# 業主方案正式合約必備條款

狀態：正式營運前必須納入合約並交由台灣法律專業人士確認。

## 名稱鎖定與付費更正

- 工作室名稱與業主顯示名稱由業主首次開通時填寫，確認送出後鎖定。
- 業主不得自行修改名稱；更正只能由平台負責人處理。
- 更名或資料更正屬付費服務。
- 合約必須明列計價方式、費用、處理範圍、所需證明、處理時間及不受理情形。
- 在費用尚未正式定價前，對外文字統一使用：「費用依合約、公告或當次報價為準」。

## 帳號與權限

- 權限綁定首次認領時登入的 LINE 帳號。
- 禁止出售、出租、轉讓、共用、改綁或自行新增其他管理者。
- 疑似冒用、違規或危害資料安全時，平台得依合約暫停權限。

## 開通同意證據

- 開通 API 必須收到帳號綁定與規範同意的明確布林值。
- 稽核紀錄保存同意版本、時間及操作主體，不保存 token 或 secrets。

## 升級、續約與降級

- 正式合約必須明列各方案升級費、升級期間的補差額計算方式、計算基準與稅費；費用尚未定案時不得杜撰金額，統一記載「費用依合約、公告或當次報價為準」。
- 合約必須明列升級的生效日期／時間、權限切換方式，以及升級不會重新邀請、不改變 LINE 綁定、不刪除既有資料。
- 續約必須記錄付款確認、新租期起訖日與方案；未確認付款不得完成續約。
- 降級預設於目前租期結束時生效，不得立即破壞或刪除資料；合約與操作畫面必須清楚列出屆時停用的能力（包含旗艦版匯入與 AI 能力）。
- 方案、租期、付款確認與生效排程的異動只能由平台負責人執行，並留下操作主體、時間與異動內容的稽核紀錄。

## 14 天旗艦版免費試用

- 試用期固定為 14 天，自業主首次成功認領邀請當天起算，建立邀請或等待認領期間不計入。
- 試用期間開放旗艦版全部功能；每間工作室原則上限用一次。
- 到期未轉正式方案時，業主端改為唯讀並保留既有資料；正式合約必須明列資料保留期限與後續處理方式。
- 試用轉為標準版或旗艦版必須由平台確認付款、生效日與正式到期日，不重新邀請、不改 LINE 綁定、不刪資料。

## 方案適用業別與評估功能

- 標準版適用美甲、美睫／睫毛嫁接與睫毛提升／翹睫管理業主，不包含霧眉／霧唇新客評估問卷。
- 旗艦版適用霧眉與霧唇業主；由平台依業主需求擇一設定霧眉或霧唇新客評估。
- 降為標準版時，既有評估與客戶資料不得刪除，但租期結束後不再對客戶開放霧眉／霧唇新客評估。
- 只有平台本人能例外延長試用，每次延長固定 14 天並留下操作主體、原到期日、新到期日與時間的稽核紀錄。
