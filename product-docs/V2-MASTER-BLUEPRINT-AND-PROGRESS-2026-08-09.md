## 一、產品最終藍圖

Juliet Studio OS 是一套共用平台、多工作室隔離的美業 LINE 系統。

平台提供兩種產品：

| 產品 | 主要客群 | 核心能力 |
|---|---|---|
| 標準版 | 美甲師、美睫師 | 預約、客戶名單、服務項目、營業時段、公告與基本店務 |
| 旗艦版 | 霧眉師、霧唇師、紋繡師 | 標準店務＋新客評估＋照片＋客戶匯入＋AI 整理與人工審核流程 |

設計原則：

- 每位業主有獨立 tenant，資料互不相通。
- LINE OA、LIFF、Worker 與 Pages 為平台共用基礎設施。
- 一般業主開通時不重建 OA、LIFF 或部署系統。
- 業主以 LINE 身分登入，後端判斷可管理的 tenant。
- AI 只負責問、收、整理、標籤與排序，不判斷是否適合施作，不承諾效果。
- 最終決定一律由老師人工審核。

## 七、資料與權限藍圖

### Tenant 隔離

- 所有工作室業務資料必須帶 tenant scope。
- 業主只能讀寫自己被授權的 tenant。
- 客戶資料、預約、照片、評估與 AI 洽詢不可跨 tenant。

### 業主權限

- LINE Provider＋LINE 身分查詢 membership。
- requested tenant 必須存在於後端回傳的 membership。
- 不接受前端任意輸入 tenant。
- 工作室選擇後再次由後端驗證。

### 平台權限

- 平台 API 固定以平台主 tenant 驗證。
- 一般業主不可進入平台管理中心。
- 平台主帳號不混入一般業主工作室清單。

### 照片與個資

- 評估照片使用私有 R2。
- 不公開 LINE user ID、token 或 secrets。
- CSV 不允許匯入 LINE user ID。
- audit log 只使用 schema 允許的 actor type 與 source。

## 八、業主訂閱開通流程

1. 平台管理中心建立工作室。
2. 選擇標準版或旗艦版。
3. 設定試用／正式租用期間。
4. 產生一次性業主邀請。
5. 私下傳給真正業主。
6. 業主用自己的 LINE 開啟。
7. 填寫工作室名稱及業主顯示名稱。
8. 同意使用規範與隱私說明。
9. 完成首次設定與 LINE 綁定。
10. 實機驗證業主端與客戶端。

一般訂閱不重做：

- LINE OA
- Messaging API
- LINE Login／LIFF
- Channel ID／LIFF ID
- 圖文選單
- Worker／Pages 部署

只有購買自有品牌 OA 時才另行建置並報價。
