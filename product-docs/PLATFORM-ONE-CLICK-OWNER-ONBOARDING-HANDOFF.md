## 一、產品目標

業主完成諮詢、確認方案與付款後，平台負責人應只需要在「平台管理中心」完成一次設定，系統便自動建立業主空間、套用正確問卷並產生一次性邀請。

業主不應理解 tenant、LIFF、D1、題庫代碼或功能旗標，也不應自行選擇霧眉／霧唇系統版本。

理想操作時間：每間工作室 3 分鐘內完成。

平台管理中心：

`https://v2-test.juliet-studio.pages.dev/owner/hub/platform/`

## 二、平台在開通前只需向業主確認的資料

### 必填

1. 訂閱方案
   - 14 天旗艦免費試用
   - 標準版
   - 旗艦版
2. 服務專業
   - 霧眉
   - 霧唇
3. 是否已確認付款
   - 免費試用不需填寫金額
   - 正式方案只記錄「付款已確認」；費用未定時不可自行杜撰
4. 業主可接收邀請的 LINE 帳號
   - 平台不代填、不記錄 LINE user ID
   - 只將一次性邀請私下傳給業主本人

### 業主首次登入自行填寫

1. 工作室名稱
2. 業主顯示名稱
3. 同意 LINE 帳號永久綁定，不得自行轉讓或改綁
4. 同意使用規範、隱私權及更名付費規則

平台不得替業主猜名稱，也不得要求業主傳 LINE user ID。

## 三、最省事的一頁式開通流程

平台管理中心應提供單一「開通工作室」精靈：

### 步驟 1｜選擇方案

- 免費試用 14 天：自動給旗艦版全部功能，期限從業主首次認領當天起算。
- 標準版：針對美甲、美睫／睫毛嫁接與睫毛提升／翹睫管理業主，提供預約與基本店務，不啟用霧眉／霧唇新客評估。
- 旗艦版：針對霧眉與霧唇業主，平台須擇一套用對應新客評估，並包含 AI、客戶匯入及旗艦能力。

### 步驟 2｜選擇業主專業

- 霧眉師 → 自動套用「霧眉新客評估」。
- 霧唇師 → 自動套用「霧唇新客評估」。

每間工作室只能啟用一份問卷。客戶端與業主端都不得自行切換另一份問卷。

### 步驟 3｜套用平台預設包

選定專業後，系統自動完成：

- 啟用該專業的題庫。
- 套用健康與安全鎖定題。
- 套用四種案件狀態。
- 套用照片要求。
- 套用 180 字內案件摘要規則。
- 套用 AI 禁止診斷、禁止藥物建議、禁止保證效果及禁止自動核准規則。
- 停用另一份問卷，但保留既有歷史資料。

### 步驟 4｜確認付款與核准

- 免費試用：勾選「我確認核准此工作室免費試用 14 天」。
- 正式方案：勾選「我已確認對方完成付款，並核准所選方案」。

### 步驟 5｜產生一次性邀請

- 邀請 24 小時內有效。
- 只能使用一次。
- 原始 token 只顯示當次，不寫入畫面紀錄或 log。
- 平台私下傳送給核准業主本人。

### 步驟 6｜業主首次認領

業主用自己的 LINE 開啟邀請，自行填寫名稱並完成兩項同意。完成後：

- LINE 身分鎖定。
- 工作室名稱及業主名稱鎖定。
- 只連到自己的工作室。
- 不可新增其他管理者。
- 不可自行改名、轉讓或改綁。

### 步驟 7｜平台驗收

平台卡片應顯示：

- 工作室名稱
- 業主名稱
- LINE 是否已綁定（不得顯示 user ID）
- 方案
- 試用／正式／到期狀態
- 到期日
- 指定問卷
- 最近一次平台異動時間

平台按「完成開通驗收」後，才把案件標為已交付。

## 四、開通後需要提供給業主的內容

平台只需傳送：

1. 業主登入入口
2. 客戶預約入口
3. 首次登入說明
4. 方案與期限
5. 問卷類型（霧眉或霧唇）
6. 客服／平台聯絡方式
7. 不可自行改名、轉讓、改綁的提醒

不要傳送：

- tenant ID
- LINE user ID
- token
- D1／R2 資訊
- Worker 或 Cloudflare 後台資料
- 內部稽核紀錄

## 五、平台的一鍵變更功能

業主日後提出要求時，平台應能從同一張工作室卡片操作：

### 問卷變更

- 一鍵切換霧眉／霧唇。
- 客戶端及業主端同步只顯示新問卷。
- 舊案件與照片不刪除。
- 未完成的舊問卷暫停。
- 寫入平台稽核紀錄。

### 名稱更正

- 只有平台本人可更正。
- 同步 tenant、店面、業主顯示名稱與品牌名稱。
- 留下更正前後紀錄。
- 費用依正式合約或當次報價，不可由系統杜撰。

### 方案管理

- 標準版升級旗艦版：設定生效日、新到期日與付款確認。
- 續約：設定新到期日並記錄付款確認。
- 降級：預設租期結束生效，不刪除資料。
- 試用轉正式：不重新邀請、不改 LINE 綁定。

## 六、平台預設題庫與客製原則

### 系統鎖定，不可修改

- 健康資料告知與同意
- 健康、用藥、懷孕或哺乳
- 傷口、水泡、紅腫、疼痛與異常狀況
- AI 不得診斷或判斷可否施作的規則
- 人工審核與預約開放規則
- 照片安全與品質限制

### 平台可依業主需求調整

- 工作室介紹
- 服務名稱
- 客人需求與偏好選項
- 非健康安全類追問
- 顯示順序
- 平台核准的照片種類

產品方向：由業主與平台溝通後，由平台統一修改及套用；業主端以查看為主，避免業主誤改安全題或破壞分支。
