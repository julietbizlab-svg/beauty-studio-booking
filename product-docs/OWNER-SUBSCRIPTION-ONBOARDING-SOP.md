# 業主訂閱開通 SOP（共用 LINE OA 模式）

## 一句話流程

一般業主訂閱時，只要在平台建立工作室、傳送一次性邀請，讓業主用 LINE 完成綁定即可；不需要為每位業主重新建立 LINE OA、LIFF 或部署系統。

## 適用範圍

- 標準版：美甲師、美睫師等一般預約管理需求。
- 旗艦版：霧眉師、霧唇師等包含旗艦功能的需求。
- 使用 Juliet Studio OS 共用 LINE OA、共用 LIFF 與共用系統入口的業主。

## 一般訂閱開通流程

### 1. 平台建立工作室

平台負責人在「平台管理中心」建立一間新的工作室：

- 填寫工作室基本名稱。
- 選擇「標準版」或「旗艦版」。
- 確認試用或租用期間。
- 確認這不是平台管理主帳號或展示／驗收 tenant。

### 2. 產生一次性業主邀請

- 系統為該工作室產生一次性邀請。
- 邀請只交給該工作室的真正業主。
- 不公開邀請內容，也不要轉傳給其他人。
- 若邀請逾期，回到平台管理中心重新產生，不必重建 LINE OA 或工作室。

### 3. 將邀請傳給業主

- 把一次性邀請連結私下傳給業主。
- 請業主用預計長期管理工作室的 LINE 帳號開啟。
- 提醒業主：完成後不可自行轉讓、改綁或新增其他管理者；若需更正應聯絡平台負責人。

### 4. 業主完成首次設定與 LINE 綁定

業主開啟邀請後：

1. 填寫或確認工作室名稱。
2. 填寫業主顯示名稱。
3. 閱讀並勾選使用規範與隱私說明。
4. 確認送出，完成首次設定與 LINE 綁定。

完成後，該 LINE 身分只會進入自己有權限的工作室。

### 5. 業主日常進入業主端

- 業主從所屬共用 OA 的「業主端」按鈕進入。
- 系統根據登入的 LINE 身分辨識權限。
- 系統自動帶業主進入自己的工作室，不需要每次輸入 tenant 或重新綁定。

### 6. 客戶進入客戶端

- 平台管理中心會為每間一般業主工作室顯示「專屬客戶入口」。
- 新建立的工作室會自動產生；既有工作室若尚未建立，可在該工作室的「管理」內按「建立客戶入口」。
- 平台負責人按「複製客戶入口」後交給該業主，業主可放在共用 OA、社群或私訊中供客戶使用。
- 客戶從專屬入口登入後，後端才依不可猜測的入口代碼辨識工作室；網址不使用也不接受 tenant ID。
- 系統只顯示該業主的店名、服務、時間與題庫，預約只寫入該業主的 tenant。

## 每位一般業主不需要重做的項目

以下是平台共用基礎設施，建立完成後可供多位業主使用：

- 不需要重新建立 LINE OA。
- 不需要重新啟用 Messaging API。
- 不需要重新建立 LINE Login 或 LIFF。
- 不需要重新設定 Channel ID 或 LIFF ID。
- 不需要重新製作、上傳或發布 OA 圖文選單。
- 不需要因新增一位業主而重新部署 Worker 或 Pages。

## 哪些情況才需要另外建立 LINE OA／LIFF

只有業主明確購買「自有品牌 LINE OA」或其他客製服務時，才另外建置：

- 使用業主自己的 OA 名稱、頭像與品牌內容。
- 使用業主自己的圖文選單。
- 使用業主自己的 Messaging API、LINE Login 或 LIFF。
- 需要獨立的歡迎訊息、自動回應或行銷設定。
- 合約要求帳號、頻道及相關資產歸業主所有。

這類需求不是一般訂閱開通，應列為「客製品牌 OA 建置服務」，另外確認工作範圍、帳號歸屬、費用與維護責任。

## 平台負責人開通檢查表

- [ ] 已建立正確的新工作室 tenant。
- [ ] 已選擇正確方案：標準版或旗艦版。
- [ ] 已確認試用／租用日期。
- [ ] 已產生新的有效一次性邀請。
- [ ] 邀請只傳給正確業主。
- [ ] 業主已用自己的 LINE 完成首次設定。
- [ ] 平台管理中心顯示 LINE 已綁定。
- [ ] 業主由共用 OA「業主端」可進入自己的工作室。
- [ ] 其他無權限 LINE 帳號不能進入該業主端。
- [ ] 客戶端顯示正確工作室、服務與方案功能。
- [ ] 平台管理中心已有該工作室的專屬客戶入口，並以另一個 LINE 客戶帳號完成預約測試。
- [ ] 手機 LINE 內實機完成至少一次主要流程測試。

## 異常處理

| 情況 | 處理方式 |
|---|---|
| 邀請已過期 | 在平台管理中心重新產生邀請，不重建 OA／LIFF。 |
| 業主尚未綁定 | 確認邀請仍有效，請業主用正確 LINE 開啟並完成首次設定。 |
| 綁定到錯誤 LINE | 不自行改資料；由平台負責人依正式更正流程處理。 |
| 業主進入錯誤工作室 | 停止操作並檢查業主權限與 tenant 對應，不公開任何 LINE user ID。 |
| 客戶端顯示錯誤內容 | 檢查客戶入口與 tenant／展示情境設定，不先重建 LIFF。 |
| 需要自己的品牌 OA | 改走客製品牌 OA 建置流程並另外報價。 |

## 不可混淆的三種工作室

1. **平台管理主帳號**：系統管理用途，不提供給一般業主，不納入一般租用統計。
2. **展示／驗收工作室**：展示標準版或旗艦版功能，不當作新業主的正式工作室。
3. **一般業主工作室**：每位付費或試用業主各自獨立的 tenant，透過一次性邀請綁定。

## 安全原則

- 不在文件、聊天或畫面截圖中公開 LINE user ID、token、Channel Secret 或其他 secrets。
- 不把一位業主的邀請交給另一位業主。
- 不直接修改 production 資料處理開通問題。
- 遠端部署或 D1 資料寫入必須另行確認授權。
- 不因一般新訂閱而改動共用 OA、LIFF 或部署設定。
